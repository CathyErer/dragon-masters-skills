# Design standard — how to map ANY Dragon Masters book to per-chapter lessons

`dm-series-data.md` holds finished per-chapter tables for **DM1 and DM2 only**.
For **DM3 and every later title**, build the table with the method below. These
eight rules were reverse-engineered from the 30 chapters of DM1 + DM2 as they
were actually taught — they are descriptive of a working course, not invented.

---

## Rule 1 — The skill comes from TEXT EVIDENCE, never from a pre-made syllabus

This is the hardest rule. Each chapter teaches what it teaches because that
chapter's text is *already shaped that way*:

| Chapter | What is in the text | So it teaches |
|---|---|---|
| DM1 Ch4 | Worm's contrast description (brown / dull / tiny wings) | Author's Word Choice |
| DM1 Ch7 | the whole chapter is a dream | 5 Senses |
| DM1 Ch9 | Rori's "sneaky look", never explained | Making Inferences |
| DM1 Ch13 | red ball → Vulcan bolts → cave-in | Cause & Effect |
| DM2 Ch4 | the potion is literally a step list | Sequencing |
| DM2 Ch9 | Kepri / Wati = Sun / Moon, a matched pair | Symbol & Contrast |

**Consequence — do not skip this:** you must READ THE WHOLE BOOK before assigning
skills. If the user has not supplied the chapter PDFs, **ask for them and stop**.
Producing a per-chapter table without the book is fabrication, not planning.

## Rule 2 — Whole-book arc: concrete → abstract

Both books have the same shape (by position in the book):

| Position | Skill type | DM1 | DM2 |
|---|---|---|---|
| first ~20% | **identification** (character, setting, compare) — most concrete | Ch1-3 | Ch1 |
| ~20-50% | **language + cause/effect + structure** | Ch4-8 | Ch2-4 |
| ~50-70% | **thinking** (inference, prediction, connection) | Ch9-10 | Ch6-9 |
| ~70-90% | **problem-solving + climax** | Ch12-14 | Ch10-11 |
| last ~10% | **theme + Story Mountain, closing the whole book** | Ch15-16 | Ch12-14 |

Chapter 1 always establishes who/where. The last chapter is always Story Mountain
+ Character Growth / Theme.

## Rule 3 — Skills MAY repeat; repetition is a feature

ESL Grade 1–3 readers need the same skill several times before it sticks. Across
the two books: Cause & Effect 4×, Making Inferences 3×, Problem & Solution 3×.

- **Repeating across books is normal and expected.** A later book does **not**
  need all-new skills. The "not yet taught" pool below is an optional expansion,
  not a checklist to complete.
- **Guideline, not a hard limit:** within one book a skill usually appears at most
  twice. Going beyond that is allowed when the text genuinely supports it — but
  you should be able to say why.
- When a skill repeats, **make the later pass harder**:
  - DM1 Cause & Effect: Ch6 single step (Bo writes the letter) → Ch13 multi-step
    chain (ball → bolt → cave-in)
  - Making Inferences: DM1 Ch9 has facial cues → DM2 Ch6 has no words at all

## Rule 4 — SKILL B is a supporting act, never a second headline

SKILL B must be one of two things: **another facet of the same passage**
(Ch7's dream = 5 Senses + Foreshadowing), or **a lower-difficulty review**
(Ch2 = Inside Traits + Asking Questions). Two headline skills do not fit in one
lesson. **Leaving SKILL B empty is better than padding it.**

## Rule 5 — The task card IS the drawing-form of that chapter's skill (1:1)

True for all 30 chapters. This is the whole secret of the card design:

| Skill | Card form |
|---|---|
| Story Elements / Outside Traits | big `.draw-frame` (draw the person / dragon) + label grid |
| Inside Traits | trait boxes + one wish box + one fear box |
| Character Traits combined | formal profile card + portrait |
| Author's Word Choice / Strong Verbs | draw it, then **circle** 2 contrast words / strong verbs |
| Name Origins | the name + draw where it came from (food / animal / nature) |
| 5 Senses | five sense panels |
| Cause & Effect | cause-chain board (2–3 panels, because / so) |
| Sequencing | step boxes (first / next / then / finally) |
| SWBST | five-panel board |
| Making Inferences | **draw only the face and the action** — no thoughts written; reader guesses |
| Making Connections | 4 panels of the past + one "what we share" box |
| Compare & Contrast | two-column compare grid |
| Predicting | three-way choice panels + a prediction box |
| Setting | big scene frame + sense labels |
| Problem & Solution | try 1 ❌ / try 2 ❌ / solution, three panels |
| Symbol & Contrast | matched-pair design (twin / sun-moon / light-dark) |
| Visualizing | 4-panel action board |
| Decision & Motivation | two-option panels + a reason box |
| Theme | paired panels (surface vs truth / before vs after) |
| Story Mountain | mountain SVG + Before/After self-portrait |

For a skill not in this table, build the card the same way: ask **"what does this
skill's thinking process look like when drawn?"** — never "how do I get the
student to write a paragraph about it?"

## Rule 6 — First half builds the world, second half tells the story

The switch is the chapter where the adventure actually launches:

- DM1: Ch1-7 build the character and dragon → **story cards from Ch8** (50%)
- DM2: Ch1-5 level the character up → **story cards from Ch6** (43%)

Do not cut at a fixed percentage. Cut at the book's "call to adventure" chapter
(DM1 flying practice, DM2 Worm's call). Landing at 40–50% is the result, not the rule.

## Rule 7 — Plant a secret, pay it off at the climax

DM1's card #5 makes the student choose a **hidden** power; Ch15 "Hidden Power
Revealed" cashes it in. **Rule: plant at least one hidden element during the
world-building half, and pay it off in a climax-chapter card.**

## Rule 8 — Fixed ending + carry-over to the next book

- Final card = Story Mountain + Before/After + **bind the book** + a hook for the
  next title ("To be continued in Book N+1…")
- The next book's first card = reuse the same character, as an "since Book N…"
  upgraded version

---

## The 7-step procedure for a new book

1. **Read the whole book.** For each chapter write one line: what stands out in
   this chapter's text? (a causal event? a description? an unexplained look? a
   dilemma?)
2. Derive each chapter's SKILL A from that evidence (Rule 1).
3. Check the ordering against Rule 2 — identification → language/cause → thinking
   → problem-solving → theme. Adjust only within what the evidence allows.
4. Check repetition (Rule 3): is a repeated skill harder the second time? If a
   skill appears more than twice in one book, can you justify it?
5. Add SKILL B where it fits (Rule 4) — leaving it empty is fine.
6. Find the switch chapter (Rule 6): world-building cards before, story cards after.
7. Turn each skill into its card form (Rule 5); plant and pay off a secret
   (Rule 7); close with the fixed ending (Rule 8).

Then write it up in the same table format as `dm-series-data.md`, and show the
user the table for confirmation **before** generating 14–16 lesson files.

## Skill pool

### Already used in DM1 + DM2 (38) — free to reuse in any later book

- **Character**: Story Elements · Outside Traits · Inside Traits · Character Traits combined · Character Growth · Bravery · Decision & Motivation · Group Dynamics
- **Language**: Author's Word Choice · Strong Verbs · 5 Senses · Visualizing · Name Origins
- **Structure**: SWBST · Cause & Effect · Problem & Solution · Sequencing · Setting · Rising Action · Resolution · Story Mountain
- **Thinking**: Making Inferences · Predicting · Asking Questions · Making Connections · Compare & Contrast (incl. Backgrounds / Abilities) · Synthesizing · Connecting Earlier Information · Connecting Text to Self
- **Theme**: Friendship · Don't Judge by Cover · Homesickness · Selflessness · Patience & Bond · Teamwork · Identity · Symbol & Contrast · Foreshadowing

### Not yet used — an **optional** expansion, not a checklist

Text Evidence · Point of View · Dialogue reveals character · Multiple Perspectives ·
Conflict types (person vs person / nature / self) · Mood & Tone · Flashback ·
Main Idea & Details · Summarizing (≠ retelling) · Author's Purpose

**How to use both lists:** when planning a new book, look at what the text
supports and treat taught and untaught skills **equally**. Introduce a new skill
only where the text naturally invites it — never to "cover something new".
